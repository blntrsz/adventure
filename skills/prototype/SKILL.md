# Prototype

## Steps

1. Write the question the prototype must answer. If it is preference, stop and ask the lane instead.
2. Build the cheapest artifact that can answer it. Throwaway. No production plumbing.
3. For UI, two or three variants on one route, labeled, toggleable.
4. Observe. The result decides the fork. Label measured vs inferred.
5. Do not graduate a prototype by renaming the folder. Production path is `/spec` then `/build`.

**Done when** the question has an observed answer and the prototype is labeled throwaway.
