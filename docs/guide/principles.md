# Principles

Steer with these names once skills exist. A citation must name the decision it changed.

| Name | When |
| --- | --- |
| Prove in prod | Before "done". Real path, real data shape, real rollback. |
| Smallest reversible | Sizing a diff or a rollout. Prefer the change you can undo. |
| Named domain | Writing logic or tickets. Terms live in CONTEXT.md. |
| Boundary at the edge | Validation, auth, partner payloads. |
| Verifiable units | Multi-step work. Each unit ends in a check. |
| Encode twice | You repeated advice. Turn it into a test, lint, or contract. |
| Gate before merge | Shipping. Empty evidence is a fail. |
| One owner | Packets, contracts, incidents. |
| Pause on irreversible | Force-push, prod data, customer message, hard cutover. |
| Subtract first | Adding on a pile. Delete the dead path first. |
| Evidence in the sentence | Claims. Measured, inferred, or guess. |
| Human for preference | Forks. Observe facts. Ask only preference, policy, or taste. |

Leaf principle skills are not in the repo yet.
