### Session pickup

Resume work from a packet or `/handoff` snapshot.

1. Find the snapshot or packet. Rank candidates. Wait if more than one fits.
2. Check that referenced files, branches, and tickets still exist.
3. Summarize complete / in-progress / not-started. Recommend one next playbook.
4. Wait. Do not start build until the user confirms.

**Reply:** recovered state, missing artifacts, recommended playbook.
