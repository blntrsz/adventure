# Setup

- `/adventure-setup`: select a Journal and record its non-secret configuration in `AGENTS.md`.
- `/explore`: map the current codebase architecture.

# Orchestration

- `/adventure`: plan or amend an Adventure and create its accepted Quest graph.
- `/quest`: execute or resume one explicitly selected Quest.
- `/to-quests`: materialize an accepted Adventure as Journal tickets.

# Workflow

- `/lore`: resolve uncertainty about how the codebase works or why it has its current shape.
- `/maintain-prover`: create or update the application's project-specific `/prove` skill.
- `/prove`: demonstrate the application behaviors required by a Quest. This skill belongs to each application and is not provided by the framework.
