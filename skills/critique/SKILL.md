# Critique

## Steps

1. Read the inbound packet, DESIGN.md, PRODUCT.md.
2. Restate the user-visible job. List states: empty, error, loading, success, permission denied.
3. Grill only interaction forks. Prototype empirical forks.
4. Accessibility bar from DESIGN.md. Failures are blockers, not nits.
5. Write accept / reject / needs-spec against the packet. Packet the next lane.

**Done when** every listed state has a verdict and the receiving lane has a done when.
