# Prove in prod

Check the consumer path. Input to stored state to output. Integrations include the other side or a boundary fake that can fail.

Rollback named. Observability that would have caught this bug. Evidence in the gate cell.

Delegates: inspect the artifact (diff, command output, UI), not the summary.
