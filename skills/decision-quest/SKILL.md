# Decision Quest Guide

1. Restate the decision, decision owner, constraints, and the latest responsible time. A factual unknown that prevents comparison becomes a scope discovery for `/adventure` rather than an invented assumption.
2. Describe genuinely viable alternatives, including retaining the current approach when applicable.
3. Compare them against the ticket's outcome and constraints. Make costs, reversibility, risks, and evidence explicit.
4. Recommend one alternative and state what would invalidate the recommendation.
5. Post the decision context, alternatives, comparison, recommendation, consequences, and unresolved dissent to the Journal.

Create a repository ADR only when the ticket requests it and the choice is hard to reverse, surprising without context, and the result of a real trade-off. The user accepts the decision and closes the ticket.
