# Research Quest Guide

Treat the ticket's Outcome as the research question and its Constraints as the evidence standard.

1. Split the question into the fewest independent claims needed for a decision or downstream Quest.
2. Search code and primary sources appropriate to each claim. Prefer repository evidence, official documentation, specifications, and original publications over summaries.
3. Verify consequential claims against source passages. Distinguish facts, inference, and unresolved uncertainty.
4. Test the findings against the downstream use named by the Quest. Research is sufficient when that use no longer depends on unsupported assumptions.
5. Post a concise Journal outcome containing the answer, evidence links or code references, implications, and remaining unknowns.

Store the report in the Journal unless the ticket explicitly requests a repository artifact. Change no application behavior. Leave acceptance and ticket closure to the user.
