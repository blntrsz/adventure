# Adventure guide

Start with `/setup-adventure`, then `/adventure-mode` for almost everything.

Give a goal, a lane, and a checkable done:

```text
/adventure-mode pm. checkout drop-off after OTP. outcome is completed sessions, not a new screen.
```

```text
/adventure-mode design critique the empty-state packet from pm. a11y is a gate.
```

```text
/adventure-mode eng. spec and tickets for the OTP retry contract with identity-platform.
```

```text
/adventure-mode em. staff the identity retry program. name the irreversible steps.
```

You do not need to name a playbook. The mode matches one.
