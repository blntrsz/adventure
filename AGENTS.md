# adventure

Adventure is an RPG inspired agent framework, where we model work as adventure and quests.

## Adventure

- Journal: GitHub Issues
- Project: blntrsz/adventure
- Adventure type: label `adventure`
- Quest type: label `quest`
- Quest labels: research → `quest: research`, prototype → `quest: prototype`, decision → `quest: decision`, architecture → `quest: architecture`, task → `quest: task`, fetch → `quest: fetch`
- Relationships: native (GitHub sub-issues linking Quests to their Adventure)
- Local Journal: Not applicable
