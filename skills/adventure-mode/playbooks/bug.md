### Bug

**Lane: eng.** Reproduce, root cause, fix, prove.

1. Reproduce on the real surface. No repro, no fix. Write the red path.
2. **diagnose**. Hypotheses from evidence. One cause.
3. Failing test or script at the seam before the fix (**tdd**).
4. Smallest reversible change. Subtract the wrong workaround if it exists.
5. **prove** the original path and a near miss. **blast-radius**.
6. Merge **gate**. **compound** if the miss should become a check.

**Reply:** cause (measured), fix, proof, lesson if any.
