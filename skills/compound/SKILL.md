# Compound

Each unit of work should make the next unit easier.

## Steps

1. What surprised you: bug, seam, partner behaviour, review miss, gate hole.
2. Write `docs/lessons/` from `templates/lesson.md`. Point at files and dashboards. Not a memoir.
3. **Encode twice:** test, lint, script, CONTEXT row, or contract clause. If it stays a note, say why encoding is wrong.
4. If the lesson is an interface, version the contract in this same change.
5. Keep the lesson short. One lesson per surprise.

**Done when** the next agent has a path to follow and, when possible, a check that fails if the lesson is ignored.
