# Wayfind

## Steps

1. State the destination in PRODUCT terms. Fog of war is the unknown decisions, not the unknown files.
2. Create decision tickets: each is one fork with options and an owning lane.
3. Sequence so resolving a decision unblocks the next frontier (same idea as grilling rounds).
4. Resolve one decision now if the owning lane is present. Otherwise packet them.
5. Stop. Do not implement inside wayfind.

**Done when** the map exists on the tracker and the next decision ticket is identified.
