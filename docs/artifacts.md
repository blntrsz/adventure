# Artifacts

- **Project Sheet**: durable orientation for a codebase.
- **Adventure**: an accepted outcome and its Quest graph, stored in the Journal.
- **Quest**: one resumable ticket in an Adventure.
  - Fetch Quest
  - Research Quest
  - Prototype Quest
  - Decision Quest
  - Architecture Quest
  - Task Quest
- **Side Quest**: a Quest not related to an Adventure.
- **Proof report**: application-behavior evidence posted to a Quest by the project-specific Prover.
- **Glossary**: canonical domain language.
- **Codebook**: codebase conventions and knowledge that are not evident from the code itself.

Adventure plans, Quest records, and Proof reports remain in the configured Journal rather than the repository.
